# Wonderlust

**Wonderlust** is a full-stack Airbnb-inspired web application built using **Node.js, Express.js, MongoDB, Mongoose, and EJS**.

The project focuses on building a real-world listing platform while learning and implementing backend concepts such as **CRUD operations, routing, reviews, sessions, cookies, validation, and error handling**.

## ✨ Features

- 🏡 **Listings** — Create, view, edit, and delete listings
- ⭐ **Reviews** — Add and delete reviews for listings
- 🛣️ **Express Router** — Modular routing for listings and reviews
- 🔐 **Sessions & Cookies** — Maintain user/session state
- 💬 **Flash Messages** — Success and error feedback for user actions
- 🛡️ **Validation & Error Handling** — Handle invalid data and missing listings
- 🍃 **MongoDB & Mongoose** — Store and manage listings and reviews
- 🎨 **Responsive UI** — Built with EJS and Bootstrap

## 🚀 Getting Started

```bash
git clone https://github.com/ATOrile098/Wonderlust.git
cd Wonderlust
npm install
```

Start the application:

```bash
node app.js
```

Or with Nodemon:

```bash
nodemon app.js
```

Then open:

```text
http://localhost:8080
```
